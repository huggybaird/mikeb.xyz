This is the project overview for my personal portfolio website. I built this site using **Astro v6** and **Tailwind CSS v4** to leverage maximum performance, static site generation, and state-of-the-art styling.

## Key Features
- **Astro v6 Content Collections** for fast content querying
- **Tailwind CSS v4** styling with utility-first classes and Dart Sass compatibility
- **Dark Mode support** using standard class toggling
- **SEO optimized** out of the box

It is fully responsive and scores a 100/100 on Google Lighthouse performance audits!
