This project showcases a rich, interactive markdown editor built with React and Tailwind CSS. It supports live preview, frontmatter linting, and dynamic syntax highlighting.

## Tech Stack
- **React 19**
- **Tailwind CSS v4**
- **Fuse.js** for full-text search index
- **Marked** for standard-compliant parsing

It's completely free and open-source!
